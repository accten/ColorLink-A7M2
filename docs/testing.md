# 上手自测清单

装好 APK 后按这五轮走一遍，大约 20 分钟。每轮都写了**预期结果**和**失败时要抓什么**。

> 当前版本：相机是真机接入前的**演示模式**——6 张示例图被当作"相机回传"走完整链路
> （落盘 → 摘要去重 → 图库 → 调色 → 导出）。所以除"真机 USB 联机"外，其余都能验。

---

## 第 1 轮 · 冒烟（3 分钟，不需要任何配置）

- [ ] 冷启动 App，首页显示 `ILCE-7M2` / `演示模式` / `已连接`，电量 78%、存储 214 张
- [ ] 「最近接收」里已有 3 张图（首次启动会种入 6 张示例图）
- [ ] 进入「图库」，看到 6 张：暮色 / 晨光 / 夜蓝 / 肤色 / 苔原 / 色卡
- [ ] 返回首页 →「进入取景」→ 画面在 6 张之间轮播，顶部 `LIVE`、`14 FPS`、`78%`
- [ ] 点一次快门 → 快门回弹 + 手机震动；退出取景后「最近接收」多一张
- [ ] 连续按 3 次快门 → 图库多 3 张，文件名时间戳递增，无重复

**失败时抓**：截图 + 设置 → 查看事件日志（看 `camera.connect` / `camera.capture` / `ingest.ok` 有没有出现）。

---

## 第 2 轮 · 调色正确性（6 分钟，最关键）

打开「图库」→ 点第 1 张（暮色），进入编辑器。

### 单参数方向（每个拉到尽再拉回）

| 操作 | 预期 |
|---|---|
| 亮度 +100 | 明显变亮（不是变灰） |
| 亮度 -100 | 明显变暗，暗部不出现彩色噪点 |
| 对比度 +100 | 亮的更亮、暗的更暗，中灰基本不动 |
| 对比度 -100 | 画面发灰、层次变平 |
| 饱和度 -100 | 变成黑白（三通道相等） |
| 饱和度 +100 | 颜色明显更艳，但不应出现色带断裂 |
| 色温 +100 → -100 | 由偏黄走回中性再偏蓝 |
| 色调 +100 → -100 | 由偏洋红走回中性再偏绿 |
| 高光 -100 | 天空/亮部压暗，暗部几乎不变 |
| 阴影 +100 | 暗部抬起，亮部几乎不变 |
| 清晰度 +100 | 中频对比增强（细节更"立"），不是单纯锐化 |
| 锐化 +100 | 边缘变硬，放大看有轻微白边属正常 |
| 颗粒 +100 | 出现噪点，且暗部比亮部明显 |
| 暗角 +100 | 四角变暗，中心不变 |

### 交互与对照

- [ ] 拖动任一滑块时画面**实时**跟着变（不应有明显延迟或先卡后跳）
- [ ] 点右侧数值 → 该参数归零
- [ ] 「按住对比」按住显示原图，松手恢复
- [ ] 「重置」→ 所有参数回默认、画面回到原图外观
- [ ] 切换 6 个预设：胶片（低饱和+颗粒）、电影感（青橙+暗角）、清透（提亮+锐化）、
      暖调（偏黄）、冷调（偏蓝）应有肉眼可辨的差异
- [ ] 换一张「色卡」图，套 3 个预设看色相有没有明显跑偏（这是"验准"用的图）

**失败时抓**：哪个参数、哪个方向、截图（含滑块读数）。这类问题基本都是着色器公式或 uniform 顺序问题。

---

## 第 3 轮 · LUT（3 分钟）

先在手机浏览器打开下面链接把文件下载到「下载」目录：

- 恒等 LUT：`https://github.com/accten/ColorLink-A7M2/raw/main/luts/sample-identity.cube`
- 青橙 LUT：`https://github.com/accten/ColorLink-A7M2/raw/main/luts/sample-teal-orange.cube`

然后在编辑器 →「预设」面板：

- [ ] 「导入 .cube」→ 选 `sample-teal-orange.cube` → 提示「已应用 … 17³」
- [ ] 画面立刻变成青橙风格（暗部偏青、亮部偏暖），与不套 LUT 明显不同
- [ ] 切到「效果」组把「LUT 浓度」从 100 收到 0 → 效果线性消失
- [ ] 再导入 `sample-identity.cube` → 画面**应该没有变化**（恒等表）；若有变化说明纹理布局/采样错了
- [ ] 随便选一个非 .cube 文件（比如一张图）→ 应提示"仅支持 3D .cube"之类，App 不崩

**失败时抓**：导入后的提示文案 + 画面截图 + 浓度 0/100 两张对照图。

---

## 第 4 轮 · AI 调色（4 分钟，需要 API Key）

设置 → AI 调色 → 填 DeepSeek API Key（`platform.deepseek.com/api_keys` 申请，`sk-` 开头），保存。

- [ ] 未填 Key 时：编辑器 →「AI」面板顶部出现黄色提示，点它跳到设置
- [ ] 填好后输入「调成胶片感，偏暖」→ 点应用 → 5~10 秒内出现「本次变化」列表（对比度/饱和度/颗粒…）+ 画面变化
- [ ] 再说「再暖一点」→ 在原参数基础上小幅叠加（不是全量重算）
- [ ] 收起/展开面板后再发指令，参数仍在
- [ ] 错误路径 1：把 Key 改错 → 提示「API Key 无效或已过期（401）」，参数保持不变
- [ ] 错误路径 2：开飞行模式再发指令 → 提示网络错误/超时，参数保持不变，App 不崩

**失败时抓**：指令原文 + 提示文案 + 耗时。日志里会有 `ai.grade.ok` / `ai.grade.http` / `ai.grade.invalid`。

---

## 第 5 轮 · 保存与导出（3 分钟）

- [ ] 编辑器右上「保存」→ 提示「已保存：xxx_edited_<时间戳>.jpg（约 xxx KB）」
- [ ] 同一张再保存一次 → 文件名变成 `...-2.jpg`，**不覆盖**上一次
- [ ] 「保存到相册」→ 首次会申请权限；授权后系统相册能看到这张图
- [ ] 图库里这张照片状态变化（小圆点/排序），原图本身没有被改动（尺寸、文件名不变）
- [ ] 设置 → 导出长边改成 2048 → 再导出一张，文件应明显变小
- [ ] 设置 → 导出日志 → 提示日志文件路径；用文件管理器打开，**不应**出现 `sk-` 或长串 base64

**失败时抓**：提示文案（保存失败会带具体原因，比如显存不足/解码失败）。

---

## 出了问题怎么反馈

1. 截图（含出错的那一屏）
2. 设置 → 查看事件日志，把最近 20 条抄下来
3. 设置 → 导出日志，把生成的 `colorlink-*.log` 一并发来

日志已经做了脱敏：不会包含 API Key 和图片数据。

## 测完之后

真机 USB 联机需要接 `expo-sony-camera` 原生模块（见 `docs/sony-transport.md`），
并在 A7M2 上验证：连接识别、实时取景、机身快门回传、拔线不崩。
这一步需要相机 + OTG 线在手边，属于下一阶段（M0）的工作。
