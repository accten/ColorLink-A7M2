# 需要连接相机的手测清单

App 里不需要相机的部分已经由自动化测试覆盖（见 `docs/qa-report.md` §9.11）；下面这些必须真机联机才能验证。
每项都有"预期"和"失败时怎么反馈给我"。

准备工作：

- 相机 USB 模式设为「PC 遥控」，用支持数据传输的线（经 hub 也行）
- 建议先进入取景页，所有参数改动都在相机上做，App 只显示
- 出问题时走「设置 → 诊断 → 导出日志到文件」，把文件名和大致时间告诉我

---

## 1. 联机与断开

| # | 操作 | 预期 |
|---|---|---|
| 1.1 | 插上相机，点「连接相机」 | 显示 `已连接`、机型 `ILCE-7M2`、电量百分比，右侧徽章 `USB 联机` |
| 1.2 | 断开相机连接 | 状态回到 `未连接`，右侧徽章**消失**（v0.2.5 修的就是"未连接却显示演示模式"） |
| 1.3 | 拔线再插上 | 自动重连；若失败，点「连接相机」能连上 |

## 2. 实时取景

| # | 操作 | 预期 |
|---|---|---|
| 2.1 | 点「进入取景」 | 左上角 `LIVE`，帧率 9~10 FPS，画面连续 |
| 2.2 | 静止 30 秒 | 帧率不下降、不黑屏；日志里 `bulk-IN retry` 次数为 0 |
| 2.3 | 转动机位/对焦 | 画面跟着变，无花屏/残帧 |
| 2.4 | 底部参数行（快门/光圈/ISO/EV/WB） | 在相机上改参数后 2 秒内刷新；读不到时显示 `—` 而不是卡住 |
| 2.5 | 「三分线」「1.8× 放大」 | 都能开/关，取景不中断 |
| 2.6 | 「结束」 | 回到首页，取景停止（相机不再空推帧） |

## 3. App 快门（远程快门 / 取景页快门键）

| # | 操作 | 预期 |
|---|---|---|
| 3.1 | 点一次快门 | 相机合焦后开火，App 只收到**一张**，回传后自动弹预览 |
| 3.2 | 连续点 3 次（间隔 3~5 秒） | 每次都只多一张，不卡、不超时 |
| 3.3 | 相机画质设成 JPEG 时的耗时 | 快门→预览 约 1.5~2.5 秒（受相机写卡影响） |

## 4. 机身快门（这一条最重要）

| # | 操作 | 预期 |
|---|---|---|
| 4.1 | 用相机机身按钮拍一张 | App 自动收到一张，预览弹出 |
| 4.2 | **连按 2~3 次** | 每次都出一张，不再出现"只有第一枪正常，之后没反应"（v0.2.2/0.2.4 修的就是这个） |
| 4.3 | 预览还开着时再按一次 | 预览**直接切到刚拍的那张**，不需要先关预览 |
| 4.4 | 取景中按机身快门 | 取景自动暂停、取回照片后自动恢复；USB 不掉线 |
| 4.5 | 相机画质设成 RAW（只出 RAW），用**机身快门**拍 | 没有 JPEG 可预览，所以不弹预览；RAW 原文件照样落盘，图库出现带 `RAW` 角标的一格，点开可解码后调色（v0.4.0） |
| 4.6 | 同上，但用 **App 里的快门** | 预期报「快门按了，但 PTP 没把图交回来」——App 快门这条路径还要求机身出 JPEG；把实际提示告诉我 |

## 5. 回传画质设置（v0.2.4 新增，v0.3.0 起支持 RAW 落盘）

| # | 操作 | 预期 |
|---|---|---|
| 5.1 | 设置 → 相机 → 回传画质，切到 `RAW` 或 `JPEG+RAW` | A7M2 属性表里没有 `0xD253`，预期弹「这台机身不支持通过 USB 改画质，请在相机菜单里改」；把结果告诉我 |
| 5.2 | 在相机菜单里把画质改成 JPEG → App 拍一张 | 只回 JPEG，速度正常，图库只多一格 |
| 5.3 | 相机画质改成 RAW+JPEG → App 拍一张 | 图库**多两格**：一格 JPEG（可预览/可调色），一格带 `RAW` 角标、页脚只写 `ARW` |
| 5.4 | 点开那格 `RAW`（v0.4.0 起） | 先出现「正在解码 RAW 原图…」，3~6 秒后进入调色器，画面是全幅 6000×4000；再点开同一张是秒进（不再解码） |
| 5.5 | 在 RAW 上调几个参数 → 保存 → 导出「原图尺寸」 | 出图是 6000×4000（左右像素与 JPEG 那张一致），调色生效 |
| 5.6 | 图库长按 → 全选 → 导出 | JPEG 和 RAW 都导出（RAW 会自动先解码），通知里是「已导出 N 张」而不是失败 |
| 5.7 | 连按机身快门 3 次（画质 RAW+JPEG） | 每次都出「JPEG + ARW」一对，共 6 格；不出现「只有第一枪正常」 |

## 6. 照片保存位置

| # | 操作 | 预期 |
|---|---|---|
| 6.1 | 三档（仅平板 / 两边都存 / 仅存储卡）各拍一张 | 大概率相机卡里都没有（固件行为，已实测过一次）。再确认一次即可 |

## 7. 预览交互（在回传照片上）

| # | 操作 | 预期 |
|---|---|---|
| 7.1 | 点画面 | 只切换按钮栏显隐；静置 2.6 秒按钮栏自动隐藏 |
| 7.2 | 双击 | 放大到 2.5 倍（以点击点为中心）；再双击还原 |
| 7.3 | 两指捏合 | 1~4 倍连续缩放；放大后单指拖动可以平移，拖不出空白 |
| 7.4 | 左上 ✕ | 关闭预览 |
| 7.5 | 右上 ⓘ | 展开文件名 / 尺寸 / 大小 / 时间 / 预览时长 |
| 7.6 | 右上 ✎ | 关掉预览并直接进入这张照片的调色器 |
| 7.7 | 系统返回键 | **只关预览**，不退出 App |

## 8. 长时间稳定性

| # | 操作 | 预期 |
|---|---|---|
| 8.1 | 取景 5 分钟不动 | 帧率稳定，无 retry，无 `live view stalled` |
| 8.2 | 取景中反复拍 10 张 | 每张都回传；取景自动恢复；相机不假死 |
| 8.3 | 拍 10 张后切到别的 tab 再回来 | 图库照片数正确，缩略图都能显示 |

## 失败时给我什么

1. 出问题的时间点（时:分）
2. 设置 → 诊断 → 查看事件日志 里最后几条（截图也行）
3. 相机当时的画质设置、是不是 RAW+JPEG、有没有插卡
4. 如果 App 显示错误提示，把提示原文告诉我

有日志我能从 `logcat` 里看到每一步的 PTP 事务和耗时，定位会快很多。
