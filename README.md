# ColorLink

把索尼 A7M2（ILCE-7M2）变成一台**手机监视器 + 调色台**：USB 连上手机，实时取景、按一次快门自动收一张照片，
在手机上做手动调色 / LUT / 自然语言 AI 调色，结果另存并导出相册。

**只调色，不做美颜**——没有磨皮、瘦脸、滤镜贴纸，只有亮度、对比、色温、高光阴影、颗粒、暗角这些摄影参数。

> 现在的版本可以直接安装试用：**演示模式**会模拟相机推流与快门，把 6 张代码生成的示例图
> （暮色/晨光/夜蓝/肤色/苔原/色卡）当作相机回传走完整链路——取景、一拍一传、调色、导出全都能跑通。
> 真机 USB 联机需要额外接入原生模块，见文末「进阶」。

---

## 功能

| 功能 | 说明 |
|---|---|
| 联机取景 | 画面全屏、保持相机比例、可切三分线、轻点 1.8× 放大；演示模式为轮播帧 |
| 一拍一传 | 快门后自动落盘到 App 私有目录，按 SHA-256 去重，失败自动重试 |
| 手动调色 | 亮度 / 对比度 / 饱和度 / 色温 / 色调 / 高光 / 阴影 / 锐化 / 清晰度 / 颗粒 / 暗角，GPU 实时预览 |
| 预设 | 内置 6 个：原图、胶片、电影感、清透、暖调、冷调 |
| 3D LUT | 导入 `.cube`（17/32/33/64），可调浓度，坏文件给出明确原因 |
| AI 调色 | 一句自然语言 → DeepSeek 返回结构化参数 JSON → 本地渲染；失败保留原参数 |
| 保存导出 | 另存为 `原名_edited_时间戳.jpg`（质量默认 92），原图 SHA-256 前后校验；可一键写进系统相册 |
| 图库 | 三列网格、倒序、长按删除（需确认，不影响相机内文件） |
| 诊断 | 事件日志（自动脱敏，不含 API Key 与图像数据），可导出为文件 |

## 环境要求

- **手机**：Android 10+，arm64（当前 APK 只含 `arm64-v8a`）
- **相机**（真机联机时）：A7M2 固件更新到最新，USB 连接模式设为「PC 遥控」，配支持数据传输的 OTG 线/转接头
- **AI 调色**（可选）：DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com/api_keys)）；其余功能完全离线

## 安装

### 方式一：下载构建好的 APK

1. 打开 [Actions → Android APK](https://github.com/accten/ColorLink-A7M2/actions/workflows/android-apk.yml)
2. 点最近一次绿色运行，页面底部 **Artifacts → colorlink-apk** 下载（需登录 GitHub）
3. 解压得到 `app-release.apk`，传到手机安装；或直接 `adb install -r app-release.apk`

也可以命令行：`gh run download <run-id> -n colorlink-apk`

> 这个 APK 用 Android 调试证书签名、只含 arm64，**适合自测**；不能上架、也不适合对外分发。

### 方式二：从源码构建

```bash
npm install
npx expo prebuild --platform android
npx expo run:android          # 装到已连接的手机
```

需要 JDK 17 + Android SDK。Expo Go 跑不了（Skia / SecureStore / MediaLibrary 都是原生模块，必须是 development build）。

## 开始使用

### 1. 连接

首次启动会自动连上「演示相机」，首页能看到 `ILCE-7M2 / 演示模式 / 已连接`、电量与存储占位、最近接收的照片。

想手动切换：点「使用演示模式」重新连接，或点「连接相机」走 USB（当前构建未接入原生模块时会明确提示原因，而不是假装成功）。

### 2. 取景

点「进入取景」：画面全屏，顶部是 LIVE / 帧率 / 电量，右上角可切换三分线，轻点画面 1.8× 放大。
底部左侧「结束」退出，中间是快门，右侧直达图库。快门后照片会出现在「最近接收」里。

### 3. 图库

底部 Tab「图库」：三列方格，有调色的照片右下角带一个小圆点。
点开进入编辑器；长按弹确认框删除（只删手机上的副本）。

### 4. 调色

编辑器下半部分有三个面板：

- **调色**：按「光 / 色 / 细节 / 效果」分组，拖动滑块即时预览；点右侧数值可单项归零
- **预设**：6 个内置风格一键套用；下面可导入 `.cube` LUT 并调浓度
- **AI**：输入「调成胶片感，偏暖」「天空更蓝一点」这类指令，或点下方示例

左上角「保存」直接写出新文件；右上角「按住对比」随时和原图核对。
面板底部「保存到相册」会额外写入系统相册，并在通知里告诉你文件名。

### 5. 设置

- **AI 调色**：填 DeepSeek API Key（存进系统安全存储，不写日志、不进构建产物）
- **导出**：长边 2048 / 3000 / 4000 / 6000（默认 4000，6000 更吃显存），JPEG 质量 80 / 90 / 95
- **相机**：是否启动时自动连演示相机；USB 模块状态；协议信息
- **诊断**：查看最近事件、导出日志文件

## 现在还不能做的

- **真机 USB 联机**：相机层已经抽象成 `ICameraTransport`，但还没接 `expo-sony-camera` 原生模块（A7M2 的 PTP2 方言需要实机验证）。接入步骤见 `docs/sony-transport.md`
- **峰值对焦**：A7M2 的 PTP 不提供该数据，改为「按住对比 / 放大查看」
- **RAW、视频、多机位**：不在当前范围

## 隐私

- API Key 只存在 Android Keystore 支撑的安全存储里，日志与构建产物里都不会出现
- 除 AI 调色会把一张缩小的预览图发给 DeepSeek 外，照片不会离开手机
- 日志只记录事件、耗时、错误码，不记录 Key、也不记录完整图像数据
